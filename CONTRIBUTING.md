# Contributing

Contributions that improve research rigor, evidence traceability, market-specific source packs, output schemas, examples, or verification are welcome.

## Skill contribution checklist

A skill should define:

- trigger / when to use;
- inputs;
- workflow;
- evidence requirements;
- explicit anti-patterns;
- structured output;
- handoff to downstream skills.

Do not add skills that are only long prompts with no evidence or output contract.

## Pull requests

Keep changes narrow. Explain what research failure mode the change fixes and provide a small example when possible.
