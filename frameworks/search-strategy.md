# Production Search Strategy

Research must use a query lattice, not one generic search query.

## 1. Build a search vocabulary

From the research scope derive:

- category terms;
- customer problem terms;
- JTBD terms;
- buyer language;
- product synonyms;
- local-language variants;
- transliterations and English brand/category names;
- substitute and DIY solution terms.

For Russian research, include Russian inflections, common abbreviations and English product/category terms when relevant.

## 2. Discovery query families

Use multiple independent query families where the available tools allow it:

### Category
`{category} {country}`
`лучшие {category}`
`{category} сервис`
`{category} программа`

### Problem / JTBD
`как решить {problem}`
`сервис для {job}`
`программа для {job}`
`чем заменить {manual_process}`

### Alternatives
`{known_competitor} аналоги`
`{known_competitor} alternative`
`вместо {category}`

### Pricing
`{competitor} цена`
`{competitor} тарифы`
`site:{domain} pricing`

### Customer signal
`{competitor} отзывы`
`{competitor} проблемы`
`{competitor} не работает`
`{competitor} альтернатива`

### GTM / proof
`{competitor} кейс`
`{competitor} клиенты`
`{competitor} партнёры`
`{competitor} интеграции`

### Strategic signals
`{competitor} вакансии`
`{competitor} запуск`
`{competitor} обновление`
`{competitor} инвестиции`
`{competitor} changelog`

## 3. Search in waves

### Wave 1 — breadth
Map the category and candidate set.

### Wave 2 — entity verification
Confirm official domains, product identity, geography and target segment.

### Wave 3 — depth
Research pricing, product, VOC, GTM and strategic signals for high-relevance competitors.

### Wave 4 — gap closure
Search only for unresolved high-impact questions and contradictions.

## 4. Saturation rule

Do not stop because an arbitrary source count was reached.

For discovery, consider the candidate set approaching saturation when two consecutive search waves produce very few new high-relevance entities and no new competitor type.

For deep research, stop when the major decision-relevant questions are either:

- supported with adequate evidence;
- explicitly unresolved and recorded as data gaps.

## 5. Snippet rule

Search-result snippets are discovery aids, not preferred final evidence. Open the underlying source whenever possible. If only a snippet is available, label it as weak/partial evidence and never use it alone for a high-impact strategic claim.

## 6. Negative-search rule

`NOT_FOUND` requires a documented search space. Record queries, source families and date. Never infer non-existence from one failed query or one unavailable page.
